# 🧶 Riya's Crochet Corner

A creative and responsive crochet e-commerce website showcasing handmade crochet products. Riya's Crochet Corner is designed to provide a simple and attractive shopping experience where visitors can explore handmade crochet creations.

## 🌸 About the Project

Riya's Crochet Corner is a personal web development project built to showcase handmade crochet products through an elegant and user-friendly interface. The website highlights creativity, handmade craftsmanship, and a simple online shopping experience.

## ✨ Features

- Attractive and responsive user interface
- Crochet product showcase
- Product descriptions and details
- Easy navigation
- Clean and user-friendly design
- Mobile-friendly layout

## 🛠️ Technologies Used

- HTML
- CSS
- TypeScript
- React
- Vite
- Tailwind CSS
